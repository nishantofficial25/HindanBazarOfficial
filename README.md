# 🛍️ HindanBazar

> A modern full-stack e-commerce marketplace built with React, Node.js, Express, and MongoDB.

HindanBazar is an online marketplace where users can browse, upload, and manage products. The project focuses on providing a smooth shopping experience with fast image loading, responsive design, and scalable backend architecture.

---

## ✨ Features

- 🛒 Product Listing & Management
- 📸 Multiple Product Image Upload
- 🔍 Search & Browse Products
- ♾️ Infinite Scrolling
- 📱 Fully Responsive UI
- ⚡ Fast Image Optimization
- 🗂️ Category-based Products
- 🔐 REST API Architecture
- 🌐 Deployed on VPS with Nginx & PM2
- ☁️ MongoDB Database Integration
